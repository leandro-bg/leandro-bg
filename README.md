### 🏗️ Mi Flujo de Trabajo y Metodologías Avanzadas

Mi proceso de ingeniería de software se basa en metodologías estructuradas y estándares de la industria para asegurar entregas predecibles y de alta calidad:

* **Spec-Driven Development (SDD):** Adopto el desarrollo guiado por especificaciones como pilar inicial. Diseño, documento y valido minuciosamente los requerimientos técnicos y los contratos de API antes de escribir código de producción. Esto me permite alinear la arquitectura con las necesidades de negocio y mitigar ambigüedades en etapas tempranas utilizando librerías de especificación como **Spec-Kit**.
* **Test-Driven Development (TDD):** Implemento ciclos estrictos de *Red-Green-Refactor*. Diseñar las pruebas unitarias y de integración de manera previa al código de producción me permite construir sistemas resilientes, documentar el comportamiento esperado de los componentes y mantener una alta cobertura de pruebas.
* **Clean Architecture + CQRS:** Estructuro mis proyectos backend dividiendo de forma estricta el dominio, la aplicación, la infraestructura y la presentación. Al implementar **CQRS** (Command Query Responsibility Segregation), separo las operaciones de lectura y escritura, optimizando el rendimiento y facilitando el mantenimiento a largo plazo.
* **Modelado de Datos Avanzado (Esquemas & UUIDs):** En el diseño de bases de datos, rechazo el uso de IDs numéricos secuenciales por motivos de seguridad y escalabilidad en sistemas distribuidos. Implemento estrictamente **UUIDs (Universally Unique Identifiers)** como llaves primarias y organizo la persistencia mediante una clara **separación por esquemas**.
