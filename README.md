### 🚀 Sobre Mí

Soy un desarrollador Full-Stack enfocado en construir soluciones backend sólidas y experiencias frontend dinámicas. Mi filosofía de desarrollo se centra en la mantenibilidad del código y la arquitectura limpia, asegurando que los sistemas puedan crecer sin acumular deuda técnica.

- 🏗️ **Arquitectura y Patrones:** Diseño mis aplicaciones utilizando **Clean Architecture** estructurada bajo el patrón **CQRS** (Command Query Responsibility Segregation) para lograr un desacoplamiento óptimo y alta escalabilidad.
- 🧪 **Calidad de Software:** Implemento **Test-Driven Development (TDD)** como pilar fundamental para garantizar la estabilidad del negocio a través de pruebas automatizadas confiables.
- 🤖 **Desarrollo Inteligente:** Adopto **Spec-Driven Development (SDD)** apoyándome en herramientas de Inteligencia Artificial y librerías de especificación (como *Spec-Kit*) para asegurar que el diseño técnico se alinee perfectamente con los requerimientos antes de escribir código de producción.
- 🗄️ **Diseño de Datos Sólido:** En mis bases de datos priorizo la separación estructural mediante **esquemas**, reforzando la seguridad y la escalabilidad global utilizando identificadores únicos universales (**UUIDs**) en lugar de enteros secuenciales de manera estricta.
